# FAISS RAG Chat

A lightweight, local retrieval-augmented generation (RAG) command-line app. It searches a line-based knowledge base with sentence embeddings and FAISS, then asks a locally hosted Ollama model to answer using the retrieved sources.

## Features

- Semantic search with normalized `all-MiniLM-L6-v2` embeddings and FAISS inner-product similarity.
- Answers generated by a local Ollama chat model, with source labels.
- Automatic FAISS index creation and reuse; the index rebuilds when `documents.txt` changes.
- No API key required. Your questions and documents are sent only to the local Ollama service and local embedding model.

## Requirements

- Python 3.10 or newer
- [Ollama](https://ollama.com/) installed and running
- An Ollama chat model, such as `llama3.2`

## Setup

Open a terminal in this project directory and create/activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies and download the default chat model:

```powershell
python -m pip install -r requirements.txt
ollama pull llama3.2
```

The first run downloads the `all-MiniLM-L6-v2` embedding model from Hugging Face. Ensure Ollama is running, then launch the app:

```powershell
python rag_chat.py
```

Ask questions at the `You:` prompt. Type `quit` or `exit` to close the application.

## Knowledge base

Add or edit `documents.txt`, using one fact or text passage per line. Empty lines are ignored and duplicate lines are removed. The app builds its FAISS index on the first run and refreshes it automatically when the document content changes.

The sample knowledge base is for demonstrating the app. Replace it with your own content before relying on answers.

## Configuration

The default chat model is `llama3.2`, and the default Ollama server is `http://localhost:11434`. Override them with environment variables if needed:

```powershell
$env:OLLAMA_CHAT_MODEL = "llama3.1"
$env:OLLAMA_HOST = "http://localhost:11434"
python rag_chat.py
```

The selected model must already be available in Ollama. For example, use `ollama pull llama3.1` before choosing that model.

## Troubleshooting

- **Could not connect to Ollama:** Start Ollama and check that `OLLAMA_HOST` points to its server.
- **Model not available:** Pull the selected chat model with `ollama pull <model-name>`.
- **Slow first run:** The embedding model downloads the first time and may take a little while to initialize.
- **No relevant sources found:** Add relevant content to `documents.txt`; retrieval results depend on the document content and similarity threshold in `rag_chat.py`.
